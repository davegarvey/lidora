# Use Lightbulb for both article-order states

Keep one stable icon for the Latest / For you toggle and use its pressed styling to show which order is active.

## Why

The control switches between two states, so changing the glyph can make it look like two different actions. A stable Lightbulb icon keeps the control's identity clear while its active color and pressed state communicate selection.

## What changes

- Use the Lucide Lightbulb icon in both Latest and For you states.
- Keep the existing 16 px size, active color, accessible label and pressed-state behavior.

## Non-goals

- Changing article ordering or selection behavior.
