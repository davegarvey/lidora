# Design

## Status leaves the reader

Any in-flow placement of a transient element in the chrome either moves neighbouring content or reserves space that is usually empty. A refresh concerns the library, not the open article, and the reader needs no action while it runs, so the reader shows nothing. The sidebar header and the collapsed rail's brand slot, which already show activity outside the reader, now also show it while an article is open. The pending Show action keeps its sidebar-header placement and, where no sidebar is visible, is offered on return to the list, as on phones.

## Star colour

The star's pressed state follows the same rule as other toggles: neutral when off, Mauve when on. Its Mauve hover wash applies only when starred, so an unstarred star hovers like the neighbouring buttons.
