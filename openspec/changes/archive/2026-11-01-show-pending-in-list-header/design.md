# Design

The list header's title is a flexible, truncating element and its toggles are fixed at the right. The Show action sits between them, so its appearance changes only where the title truncates; the toggles do not move. The header is shown whenever the list has feeds, which covers phones, the three-pane desktop workspace with an expanded or collapsed rail, and the single-column desktop list. When the list is not visible (phone reader, desktop focus mode), the action appears on return, as before.
