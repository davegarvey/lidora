# Design

Use Lucide's `size` prop to set desktop navigation and toolbar CTA icons to 16 px. Keep article-row actions at 14 px and compact inline actions, such as tag removal, at 12 px. The mobile reader action bar may use 16–18 px icons to suit its larger touch targets.

The river header uses `Lightbulb` when For you ordering is selected and `ArrowDownWideNarrow` when Latest is selected. This preserves the sorting metaphor for Latest and gives recommendation-based ordering a clear, non-AI symbol.

Button dimensions and touch target sizes remain unchanged.
